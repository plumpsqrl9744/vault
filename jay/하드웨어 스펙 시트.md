## 1. Teensy 4.1 (제어 MCU) — Joy-IT 데이터시트

로봇의 두뇌. 고성능 마이크로컨트롤러 개발보드.

| 항목 | 스펙 |
| --- | --- |
| 프로세서 | **iMXRT1062DVJ6 ARM Cortex-M7** |
| FPU | 32 & 64 bit |
| 클럭 | **600 MHz** |
| Flash | 7,936 kB |
| RAM | **1,024 kB** |
| EEPROM | 1,080 B (emu) |
| Ethernet | 10/100 Mbit DP83825 PHY |
| 공급 전압 | 3.6 ~ 5.5 V |
| 로직 레벨 | **3.3 V** |
| 디지털 핀 | 55 |
| 아날로그 입력 | 18 |
| 핀당 최대 전류 | 10 mA |
| 통신 | **USB, Serial, SPI, I2C, CAN**, Digital Audio IN/OUT, SD Card, Ethernet |
| 기타 | Lock 버전(TEENSY41_LOCK): 펌웨어 영구 보호 기능 — 무단 읽기/수정 방지 |

- **핀아웃 요점**: 3.3V 로직(250mA 한도), Vin 3.6~5.5V. UART(TX/RX) 다수 — ESP32 브릿지 연결은 이 시리얼 핀 사용.
- ⚠️ **5V 톨러런트 아님(3.3V 로직)** — ESP32도 3.3V라 UART 직결 OK, 5V 센서 연결 시엔 레벨 시프터 필요.

## 2. Raspberry Pi 5 (SBC 후보) — 공식 Product Brief

"everything computer". Teensy(실시간 제어)와 달리 리눅스 돌리는 범용 컴퓨터 — 영상 처리·관찰 렌즈 스트리밍 같은 무거운 작업 후보.

| 항목 | 스펙 |
| --- | --- |
| SoC | **Broadcom BCM2712** — 2.4GHz 쿼드코어 64bit **Cortex-A76** (RPi4 대비 CPU 2~3배) |
| GPU | VideoCore VII 800MHz (OpenGL ES 3.1, Vulkan 1.2), 듀얼 4Kp60 HDMI + HDR |
| RAM | LPDDR4X-4267 — **1/2/4/8/16GB 옵션** |
| 무선 | 듀얼밴드 802.11ac Wi-Fi, BT 5.0/BLE |
| USB | USB 3.0 ×2 (동시 5Gbps) + USB 2.0 ×2 |
| 유선랜 | Gigabit Ethernet (PoE+ — 별도 HAT 필요) |
| 카메라/디스플레이 | **4-lane MIPI 트랜시버 ×2** (카메라/디스플레이 조합 자유, 1.5Gbps ×4레인) |
| 확장 | **PCIe 2.0 x1** (M.2 HAT 등 별도 어댑터 필요), 40핀 GPIO 헤더 |
| 전원 | **5V/5A USB-C** (PD 지원) |
| 기타 | RTC(외부 배터리), 전원 버튼, microSD SDR104 |
| 동작 온도 | 0~70°C |
| 생산 보장 | **최소 2036년 1월까지** |
| 가격 | 1GB $45 / 2GB $65 / 4GB $110 / 8GB $175 / 16GB $305 |
| 특이점 | 자체 설계 **RP1 사우스브리지** — I/O 대역폭 대폭 향상 (USB 2배, MIPI 3배, SD 2배) |

- ⚠️ **5V/5A(25W) 전원 요구** — 로봇 배터리 설계 시 부담되는 수치. Teensy(수백 mA)와 급이 다름.

## 3. GIGAIPC iTXL-6412A (산업용 마더보드) — MEHLJAT-SI

Thin Mini-ITX 산업용/임베디드 보드. 로봇 탑재보다는 **현장 서버/관제 PC**급.

| 항목 | 스펙 |
| --- | --- |
| 폼팩터 | Thin Mini-ITX (170×170mm) |
| CPU | **Intel Celeron J6412** (Elkhart Lake 10nm, 4코어 4스레드, ~2.6GHz, TDP 10W) 온보드 |
| 메모리 | DDR4 SO-DIMM ×2 (최대 32GB, DDR4-3200 듀얼채널) |
| LAN | **GbE ×2** (Realtek — RJ45 ×2) |
| 영상 출력 | HDMI 2.0 ×2 (4096×2160@60Hz) + LVDS(1920×1080) + eDP — 독립 3화면 |
| 스토리지 | SATA 6Gb/s ×1, M.2 2280 M-Key (PCIe x2, SATA 겸용) |
| 확장 | PCIe x1 (Gen3 x1), M.2 2230 E-Key (PCIe x1, USB 2.0 — Wi-Fi 모듈용) |
| COM 포트 | **×4** — RS-232/422/485 ×1(+RI/5V/12V), RS-232 ×1(+RI/5V/12V), RS-232 ×2 |
| USB | USB 3.2 Gen1 ×3 + USB 2.0 ×1 (후면) + USB 2.0 헤더 ×5 |
| 내부 I/O | GPIO(8bit)+SMBus, 백라이트 컨트롤, 시스템/CPU 팬 헤더 등 |
| 전원 | DC Jack **+12V/19~24VDC** (또는 4핀 ATX) |
| OS | Windows 10 (x64) |
| 동작 환경 | 0~60°C, 습도 0~90% (비응축) |

- **용도 확정**: 로봇 IP65 케이싱 내 탑재 — **AOS 라이브러리 인터페이스·데이터 송수신 + Wi-Fi 관문** 역할 ([[ERobot 시스템 아키텍처]] 참조).
