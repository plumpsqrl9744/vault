# Claude Code 플러그인 및 스킬 구성

#claude-code #superpowers #skills #plugin

> Claude Code에 설치한 플러그인과 커스텀 스킬 목록 및 용도 정리

## 플러그인

### Superpowers (v5.0.7)

Claude Code의 작업 품질을 높이는 방법론 스킬 모음. 자동으로 적용됨.

| 스킬 | 트리거 | 용도 |
|-|-|-|
| brainstorming | 기능 생성/수정 전 | 요구사항 탐색, 의도 확인 |
| writing-plans | 멀티스텝 작업 전 | 구현 계획 수립 |
| executing-plans | 계획 실행 시 | 리뷰 체크포인트 포함 실행 |
| test-driven-development | 구현 전 | 테스트 먼저 작성 |
| systematic-debugging | 버그 발생 시 | 체계적 원인 분석 |
| verification-before-completion | 완료 선언 전 | 실제 동작 검증 필수 |
| requesting-code-review | 기능 완성 시 | 코드 리뷰 요청 |
| dispatching-parallel-agents | 독립 작업 2개+ | 병렬 에이전트 실행 |
| finishing-a-development-branch | 브랜치 작업 완료 시 | merge/PR/cleanup 옵션 제시 |

## 커스텀 스킬

### commit
- **트리거**: "커밋해줘", "commit"
- **동작**: 브랜치명에서 JIRA 번호 추출 → 변경 내용 분석 → `[JIRA-NUMBER][TYPE] 설명` 형식 메시지 자동 생성
- **TYPE**: FEAT, FIX, UPDATE, REFACTOR, ADD, REMOVE, STYLE

### vault-lint
- **트리거**: "볼트 점검해줘", "vault-lint"
- **동작**: 옵시디언 볼트 건강 점검 (고아 페이지, 깨진 링크, _index 불일치, 90일 미갱신)
- **출력**: 리포트만 출력, 자동 수정 없음

### meeting-notes
- **트리거**: "회의록 정리해줘", "회의록"
- **동작**: 녹취록/메모 → 옵시디언 회의록으로 변환
- **규칙**: 원본에 명시적으로 있는 내용만 작성, 추론 금지

### teams
- **트리거**: "팀즈 구성해줘", "팀 구성"
- **동작**: 작업 규모에 맞는 에이전트 팀 프리셋 구성
- **프리셋**: 프론트만(2명), 백만(2명), 풀스택(3명), PRD 신규(4명), 분석/설계(2~8명)

## 설치 방법

```bash
# superpowers 플러그인
claude plugins install superpowers --marketplace claude-plugins-official

# 커스텀 스킬 (skills/skills/{name}/SKILL.md 에 정의)
# ~/.claude/skills/skills/ 디렉토리에 폴더 생성 후 SKILL.md 작성
```
