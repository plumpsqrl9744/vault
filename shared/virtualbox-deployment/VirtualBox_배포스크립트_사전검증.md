# VirtualBox 배포 스크립트 사전 검증

#virtualbox #ubuntu #배포 #검증

> 실서버 배포 전 Oracle VirtualBox에서 배포 스크립트를 사전 검증하는 워크플로우

## 목적 (Why)

실서버에 배포 시 오차 없이 한번에 설치 완료하기 위함.
실서버와 동일한 OS 환경을 VirtualBox에 구성하여 배포 스크립트를 사전 테스트한다.

## 검증 환경 구성

| 항목 | 설정 |
|-|-|
| 가상화 도구 | Oracle VirtualBox |
| Guest OS | Ubuntu (실서버와 동일 버전) |
| 네트워크 | 실서버 네트워크 구성과 동일하게 설정 |
| 리소스 | 실서버 스펙에 맞춰 CPU/메모리/디스크 할당 |

## 워크플로우

### 1. VM 환경 준비

- 실서버와 동일한 Ubuntu 버전으로 VM 생성
- 네트워크, 디스크, 메모리 등 실서버 스펙 반영
- 기본 패키지 상태를 실서버와 일치시킴

### 2. 배포 스크립트 전송 및 실행

```bash
# VM에 스크립트 전송
scp deploy.sh user@vm-ip:/home/user/

# 실행 권한 부여
chmod +x deploy.sh

# 스크립트 실행
./deploy.sh
```

### 3. 검증 항목

- [ ] 의존성 패키지 설치 정상 완료
- [ ] 애플리케이션 빌드 성공
- [ ] 서비스 등록 및 기동 확인
- [ ] 포트 바인딩 정상
- [ ] 로그 출력 확인
- [ ] 웹 접속 테스트

### 4. 결과 판정

- 모든 항목 통과 → 실서버 배포 진행
- 실패 항목 존재 → 스크립트 수정 후 VM 스냅샷 복원하여 재검증

## 팁

- VM 스냅샷을 스크립트 실행 전에 저장해두면 반복 테스트 용이
- 실서버와 OS/패키지 버전 불일치가 가장 흔한 실패 원인
- 검증 완료 후 동일 스크립트를 실서버에 그대로 적용
