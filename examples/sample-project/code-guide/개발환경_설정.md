# 개발환경 설정

#docker #nodejs

## 설명

로컬 개발환경을 구성하는 방법을 정리한다.

## 왜 ���는지 (Why)

신규 입사자나 환경 재구성 시 빠르게 셋업하기 위함.

## 사용법 (Do)

```bash
# 1. 의존성 설치
npm install

# 2. 환경변수 설정
cp .env.example .env

# 3. DB 컨테이너 실행
docker-compose up -d

# 4. 개발 서버 ���행
npm run dev
```

## 주의사항
- Node.js 18+ 필요
- `.env` 파일은 git에 올리지 않는다
